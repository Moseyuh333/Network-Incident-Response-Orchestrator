## Project nay la gi?

N.I.R.O. la web app xu ly su co an ninh mang.

Ban dua log/su kien vao, app se:

1. Doc log.
2. Phat hien dau hieu tan cong.
3. Tao incident.
4. Cho agent/LLM phan tich.
5. De xuat cach xu ly.
6. Doi ban approve truoc khi execute.

## Nen nho 5 y nay

- `Operations` la man hinh chinh.
- `Events Logs` la noi xem log dau vao.
- `Incidents` la noi xem su co da tao.
- `Approvals` la noi duyet hanh dong.
- `ML Models` la noi cai API key va model LLM.

## Khong nen sua gi neu chua chac

- Khong commit `.env`.
- Khong in API key vao docs/log.
- Khong tat safe mode neu chi dang test.
- Khong xoa `.pi` neu chua backup.
